# 환경 센서 대시보드 — 구현 프롬프트 (Claude Code용)

> 사용법: 이 문서를 작업 브리프로 그대로 넘기거나 `CLAUDE.md`에 붙여 프로젝트 컨텍스트로 둔다.

## 1. 목표

스마트 팩토리 환경 센서 데이터를 실시간 모니터링하고, 계산된 **불량률**을 함께 보여주는 React 대시보드 화면을 구현한다. 핵심은 정규화된 4개 측정값 추이와 불량률을 **하나의 차트에서 초점을 전환하며** 보는 것이다.

## 2. 시스템 맥락 (참고)

데이터 파이프라인: `센서 → ESP32(MQTT publish) → MQTT broker → Python 수집기 → TimescaleDB(하이퍼테이블) → FastAPI(집계·정규화·불량률 계산) → React 대시보드`.
이번 작업 범위는 **(a) 대시보드용 FastAPI 엔드포인트 1개**와 **(b) React 대시보드 화면**이다. MQTT 수집기와 DB 스키마(하이퍼테이블)는 이미 존재한다고 가정한다.

## 3. 기술 스택

- Frontend: **React + TypeScript**, 차트는 **Recharts**(권장), 데이터 패칭은 **TanStack Query**(폴링 10초).
- Backend: **FastAPI(Python)**, DB는 **TimescaleDB(PostgreSQL)**.
- 스타일: CSS Modules 또는 Tailwind. **다크/라이트 모드 모두 대응**.
- 브라우저 저장소(localStorage 등)에 상태를 의존하지 말 것. UI 상태는 React state로 관리.

## 4. 측정 항목과 색상 (고정)

| 항목     | 키            | 단위  | 색상      |
| -------- | ------------- | ----- | --------- |
| 온도     | `temp`        | °C    | `#3B82F6` |
| 습도     | `hum`         | %     | `#EC4899` |
| 가스     | `gas`         | ppm   | `#8B5CF6` |
| 미세입자 | `pm`          | µg/m³ | `#14B8A6` |
| 불량률   | `defect_rate` | %     | `#E0473C` |

- 기본 조회 구간: 당일 `00:00~23:59`(이미지 시안 기준).

## 6. 불량률 계산 — 임시 휴리스틱 (추후 모델로 교체)

> ⚠️ 지금은 **placeholder**다. 추후 학습된 분류 모델의 위험 점수(0~100)로 대체한다. 코드에 그 교체 지점을 함수로 분리해 둘 것.

규칙: **습도와 가스가 동시에 높을 때** 불량률이 오른다(온도 단독 상승 등 단일 변수만으로는 오르지 않음). 정규화값 `humN`, `gasN`(0~100) 기준:

```python
defect_rate_i = clamp((humN/100) * (gasN/100) * 135 - 18, 0, 100)
# 인접 3점 이동평균으로 살짝 평활화
```

## 7. 화면 레이아웃

- 3열 구성: **[좌측 박스 2개 | 중앙 차트 | 우측 박스 2개]**, 상단에 헤더.
- 헤더: 제목 + **현재 불량률** 표시 + **세그먼트 토글 버튼 `[측정값 | 불량률]`**.
- 좌측: 온도·습도 / 우측: 가스·미세입자.
- 반응형: 폭이 좁아지면 박스가 차트 위/아래로 재배치(stack).

### 측정 박스 내용

색 점 + 항목명 + **상태 pill**(정상/경고/위험) + 큰 현재값+단위 + **스파크라인**(최근 추이). (선택) 최고·최저·평균.

- pill 색: 정상 `#1D9E75`, 경고 `#C77A0A`, 위험 `#E0473C` (옅은 배경 + 진한 글자).

## 8. 중앙 차트 명세

- **X축 = 시간**, **Y축 = 정규화 값(0~100)**. 불량률도 0~100%라 같은 축을 공유.
- 4개 측정값 선(각 항목 색) + **불량률 선(빨강 `#E0473C`, 점선 + 하단 면 채움)** — 측정값 선과 **형태로도 구분**되게 한다.
- 가로 그리드(0/25/50/75/100), 시간축 라벨(예: 4시간 간격).
- hover 툴팁: 해당 시각의 **4개 실측값(단위 포함) + 불량률(%)**.

## 9. 토글 동작 (핵심)

상단 세그먼트 버튼으로 **초점**을 전환한다. 전환은 `opacity` transition 0.25초.

| 모드              | 측정값 선                       | 불량률 선/면                             |
| ----------------- | ------------------------------- | ---------------------------------------- |
| **측정값** (기본) | opacity `1.0` (선명)            | opacity `~0.3` (흐리게, **숨기지 않음**) |
| **불량률**        | opacity `~0.16` (배경처럼 남김) | opacity `1.0` + 더 굵게 + 면 채움 노출   |

- 흐려지는 쪽을 **완전히 숨기지 말 것**. 불량률을 볼 때도 "무엇이 그 불량률을 만들었는지" 배경으로 함께 읽혀야 한다.

## 10. 권장 추가 (선택, 가능하면 포함)

- 불량률 **70% 이상 구간**에 옅은 붉은 음영(위험대 표시).
- **측정 박스 클릭** 시 해당 항목 선만 강조(나머지 흐림).

## 11. 수용 기준 (Acceptance Criteria)

- [ ] 토글로 측정값 ↔ 불량률 초점이 부드럽게 전환된다.
- [ ] 4개 항목이 정규화되어 한 축에서 추이 비교가 가능하다.
- [ ] 불량률 선이 **습도·가스 동반 상승 구간**에서 상승한다(휴리스틱 검증용 목업 데이터로 확인).
- [ ] 온도만 단독 상승하는 구간에서는 불량률이 오르지 않는다.
- [ ] 박스에서 **실제 단위·현재값·상태**를 확인할 수 있다.
- [ ] 다크/라이트 모드 모두 가독성이 유지된다.
- [ ] API 미연결 상태에서도 목업 데이터로 화면이 렌더된다(개발 편의).

## 12. 구현 순서 제안

1. API 응답 타입 정의 + 목업 데이터 생성기(섹션 6 휴리스틱 포함).
2. 측정 박스 컴포넌트(값/상태/스파크라인).
3. 중앙 차트(4선 + 불량률 선/면, 정규화, 그리드, 툴팁).
4. 토글 상태 + 초점 전환 스타일.
5. TanStack Query로 실제 API 연동(폴링) + 목업 폴백.
6. FastAPI 엔드포인트 구현(TimescaleDB 집계 + 불량률 함수).

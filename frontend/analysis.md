# 통계(분석) 탭 — 패널별 계산법 · 예측 근거 · 신빙성

각 패널마다 세 가지를 정리한다: **계산법**(수식), **왜 이걸 보는가**(실제 산업 자료로 뒷받침되는 도메인 근거), **신빙성**(실측 검증된 것 vs 아직 가정인 것).

## 행 1: 설비 이상 예측

### 온도 이동평균 추세

- **계산법**: 상단에서 고른 조회 기간(1일/1주일/1개월, 기간이 길수록 조회 간격도 15분→1시간→4시간으로 넓어짐) 데이터 전체에 이동평균(6포인트 창) 적용 → 그중 최근 8시간 구간만 잘라 선형회귀 → 시간당 변화율(기울기) → `(위험임계 − 현재값) / 변화율`로 도달 예상시간(ETA)
- **왜 이걸 보는가**: 리소그래피 공정은 온도에 극도로 민감해서, 첨단 클린룸은 **±0.1℃ 수준의 온도 제어**를 요구한다 — 작은 온도 변화도 웨이퍼 열팽창을 일으켜 패턴 정렬 오류·선폭(feature size) 변화로 이어지기 때문이다. 증착 공정에서는 막 두께 불균일·기공 형성, 이온주입에서는 도펀트 확산 이상, CMP(화학적기계연마)에서는 평탄화 불균일까지 유발한다 ([출처](#출처) 1번). 장비 이상은 온도가 갑자기 튀기보다 **서서히 상승**하며 시작되는 경우가 많아, 순간값보다 "얼마나 빠르게 오르고 있는가(기울기)"를 보는 게 더 이른 신호가 된다.
- **신빙성**: 계산 방법(이동평균·선형회귀·ETA)과 "정밀 온도 제어가 수율에 직결된다"는 근거는 실제 자료로 뒷받침된다. 다만 여기 쓰인 임계치(경고 35℃/위험 45℃)는 대시보드 탭에 적용한 실측 클린룸 기준(22.0±0.5℃, [루트 README 참고자료](../README.md#참고자료) 1번)과 **다른 별도 설정값**이라 아직 통일이 안 됐다 (`config.ts`의 `THRESHOLDS.temp`). "±0.1℃ 요구"라는 업계 기준에 비하면 지금 임계치(±수십 배 느슨함) 자체도 데모 수준이라는 점을 감안해야 한다.

### 가스 농도 이동평균 추세

- **계산법**: 온도와 동일한 로직을 가스(MQ-2) 값에 적용.
- **왜 이걸 보는가**: ⚠️ 여기서부터는 "수율 예측"이 아니라 **안전(safety)** 관점의 근거다. MQ-2(가연성가스)는 원래 KOSHA 가스누출감지경보기 기준([루트 README 참고자료](../README.md#참고자료) 2번)에 따라 누출을 조기에 감지해 폭발·화재를 막기 위한 센서지, 수율과의 상관관계를 연구한 자료는 없다. "온도·가스 동반 상승"을 보는 이유는 화학반응/연소 관련 이상(예: 배기 시스템 고장)이 진행되면 두 값이 같이 움직이는 경우가 많다는 공학적 추론이지, 검증된 정량 연구는 아니다.
- **신빙성**: ⚠️ MQ-2 값은 raw ADC(0~4095)라서, 임계치(경고 300/위험 500)가 실제 가스 농도 단위(ppm·%LEL)와 안 맞는 placeholder다. "추세를 본다"는 방법론은 유효하지만, 절대 수치(ETA 등)는 신뢰하면 안 된다.

### 설비 이상 조짐 카드

위 두 추세를 종합해 상태(정상/주의/위험)를 판정하고 ETA를 요약 표시. 판정 규칙: 온도·가스 둘 중 하나라도 위험임계 도달 시 `danger`, 경고임계 도달이거나 상승 추세 감지 시 `warning`, 아니면 `normal`. 계산법·신빙성은 위 두 패널과 동일.

## 행 2: 공기질 추세

- **계산법**: 행 1과 동일한 이동평균+회귀 로직을 공기질(MQ135) 값에 적용.
- **왜 이걸 보는가**: 클린룸 등급(ISO 14644)은 원래 공기 중 **입자(particle) 농도**로 정의되고, 반도체 수율과 직결되는 핵심 지표다. 한 학술 연구는 서브미크론 공정에서 78% 수율을 달성하려면 공정 단계당 0.001개/cm² 이하의 killer defect만 허용되고, 디바이스 치수가 1/3~1/2로 축소될 때마다 파티클 농도를 거의 10배 줄여야 수율을 유지할 수 있다고 분석했다 ([출처](#출처) 2번). 필터·환기 시스템이 서서히 저하되면 공기질이 완만하게 우상향하는 패턴을 보이는 게 일반적이라, 이 추세를 조기에 잡아 필터 교체·환기 점검 타이밍을 예측하려는 것.
- **신빙성**: ⚠️ **중요한 차이가 있다.** 위 연구는 "입자 개수"(particle count, 광학식 파티클 카운터로 측정) 기준인데, 지금 우리 센서(MQ135)는 입자가 아니라 **가스상 화학물질(암모니아·벤젠·CO2 등)**을 측정하는 센서다. 즉 "공기질 저하가 수율에 영향을 준다"는 큰 방향은 산업 전반에서 사실이지만, 그 연구의 정량적 수치를 지금 우리 MQ135 값에 직접 대입할 근거는 없다. 게다가 MQ135도 raw ADC(0~4095)라 임계치(경고 75/위험 100)가 실제 단위와 안 맞는 placeholder다.

## 행 3: 환경 안정성 (기압 추세 + 센서 간 상관관계)

> 이전 버전에는 이 행이 "수율 상관관계"(습도-불량률 산점도, Top3 카드, 배너)였다. `defect_rate`가 실측이 아니라 지어낸 값이라는 문제가 있어 `d918e9e`/`f19c117` 리팩터에서 해당 패널을 전부 제거하고, 기압 추세 + 순수 센서 간 상관관계로 바꿨다.

### 기압 이동평균 추세

- **계산법**: 행 1과 동일한 이동평균+회귀 로직을 기압 값에 적용. 다만 기압은 **낮아질수록** 위험이라 하락 방향 기울기를 감지한다(`buildPressureTrend`의 `direction: 'falling'`).
- **왜 이걸 보는가**: 클린룸은 보통 주변 공간보다 압력을 높게(양압) 유지해서 오염물질 유입을 막는데, ISO 14644-4는 등급이 다른 공간 사이에 **5~15Pa**의 차압을 권장한다 ([출처](#출처) 5번). "기압(차압)이 떨어지면 오염 위험이 커진다"는 실제 표준에 근거한 이야기라, 하락 추세를 조기에 잡으려는 것.
- **신빙성**: 계산법·근거 모두 신뢰 가능. 다만 화면 임계치(경고 1005hPa/위험 995hPa, `config.ts`)는 ISO 14644-4의 "차압(5~15Pa, 두 공간 간 압력 차이)" 개념을 그대로 옮긴 게 아니라 절대 기압값에 임의로 설정한 수치라, 실제 차압 기준과는 별도의 placeholder다.

### 센서-센서 상관계수 히트맵

- **계산법**: 5개 센서(온도/습도/가스/공기질/기압) 서로 간 피어슨 상관계수를 5×5 매트릭스로 표시.
- **왜 이걸 보는가**: 센서끼리 강하게 얽혀 움직이면(예: 온도가 오를 때 가스도 같이 오름) 공정·설비상 물리적으로 연결된 원인을 유추하는 단서가 된다.
- **신빙성**: ✅ 전부 실측 센서값 간 상관계수라 그 자체로 신뢰 가능. 이전 버전엔 여기에 지어낸 `defect_rate`와의 상관계수도 섞여 있었지만 (`deriveAnalysis.ts` 주석: "불량률은 실측이 아니라 지어낸 값이라 여기서는 다루지 않는다") 완전히 제거했다.
  - 참고: 습도 자체의 ESD·수율 연관성(저습도가 정전기 방전 위험을 높인다는 것, [출처](#출처) 3번; 반도체 클린룸 권장 습도 35~45%RH, [출처](#출처) 4번)은 여전히 실제 근거가 있는 이야기다. 다만 지금 화면에는 그걸 직접 보여주는 패널(습도-불량률 산점도)이 없고, 히트맵의 "습도-타 센서" 셀로만 간접적으로 드러난다.

## 요약

| 구분 | 신뢰 가능 | 아직 데모/가정 |
|---|---|---|
| 계산 방법(이동평균·회귀·상관계수·ETA) | ✅ 표준 기법, 그대로 신뢰 가능 | — |
| 온도·습도·기압 원시값 | ✅ 실측 | — |
| "온도 정밀 제어가 수율에 영향" (±0.1℃ 기준) | ✅ 실제 산업 자료 근거 | 화면의 임계치(35/45℃)는 그 기준과 무관한 별도 설정 |
| "습도가 ESD·수율에 영향" (35~45%RH 권장) | ✅ 실제 산업 자료 근거 | 화면엔 습도 전용 패널이 없음 — 히트맵의 습도-타 센서 상관관계로만 간접 확인 |
| "공기질(입자)이 수율에 영향" | ✅ 실제 연구 근거 있음 | 그 연구는 입자 개수 기준 — 우리 센서(MQ135)는 가스 측정이라 수치 직접 대입 불가 |
| "차압이 오염 위험에 영향" (5~15Pa) | ✅ ISO 14644-4 근거, 자체 추세 패널로 화면에 반영됨 | 화면 임계치(1005/995hPa)는 차압(5~15Pa) 기준을 그대로 옮긴 게 아니라 별도 설정값 |
| 센서 간 상관계수(히트맵) | ✅ 전부 실측값 기반, 신뢰 가능 | — |
| 가스(MQ-2) 추세가 "수율"과 관련 있다는 것 | — | ❌ 근거 없음. 원래 안전(누출 감지) 목적 센서 |

# 예측 분석 대시보드 (분석 탭) — 구현 프롬프트 (Claude Code용)

> 기존 센서 대시보드 앱에 **"분석" 탭**을 추가한다. 첨부 시안(예측 분석 대시보드)을 기준 레이아웃으로 삼는다.

## 0. 값의 출처 (가장 중요)

- **모든 임계치·상수·색상·라벨·표시 수치는 `claude.md`에 정의되어 있다.**
- 이 파일을 **단일 출처(single source of truth)** 로 삼는다. 숫자를 코드에 **하드코딩하지 말 것.** (예: 경고 35°C, 위험 45°C, 300/500ppm, 경고 PM 75, 상관계수, 변화율, D+12일, r=0.81 등은 모두 md에서 읽는다.)
- md에 없는 값이 필요하면 **임의로 채우지 말고**, 어떤 키가 필요한지 md에 추가하도록 제안한 뒤 진행한다.
- 구분:
  - **설정값**(임계치·색상·라벨·이동평균 윈도우·감지 파라미터) → 항상 md.
  - **산출값**(이동평균·변화율·상관계수·회귀·ETA) → 시계열 데이터로 **계산**. 단, 계산에 쓰는 파라미터와 표시 임계는 md.
  - 실데이터 파이프라인 연결 전에는 md가 제공하는 **샘플/시드 값**으로 렌더한다.

## 1. 위치 / 스택

- 기존 앱의 상단 탭 `실시간 | 분석 | 이력 조회` 중 **분석** 탭. 좌측 사이드바(환경 센서 / 분석 / 알람 이력 / 임계치 설정)는 기존 것을 재사용.
- **React + TypeScript**, 차트 **Recharts**(단, 상관 매트릭스 히트맵은 커스텀 컴포넌트), 데이터 **TanStack Query**, 백엔드 **FastAPI + TimescaleDB**.
- **다크 모드가 기본**(시안 기준), 라이트 모드도 지원. 브라우저 저장소 사용 금지, UI 상태는 React state.

## 2. 전체 레이아웃

- 헤더: 제목 `예측 분석 대시보드`, 서브 `esp32-A1 · 설비 이상 예측 · 필터 교체 예측 · 수율 상관관계 (SECOM 기반)` (텍스트는 md/props).
- 본문은 **3행 그리드**, 각 행 = **[좌측 차트 2개 | 우측 상태 카드 1개]**.
  - 좌측 2/3 영역에 차트 2개 나란히, 우측 1/3에 예측/상태 카드 1개.
- 반응형: 폭이 좁아지면 차트가 1열로, 우측 카드는 아래로 재배치.

---

## 3. 행 1 — 설비 이상 예측

### 패널 1-1: ① 온도 이동평균 추세

- **ComposedChart(Line)**. 시리즈: `온도 실측`(옅은 회색 선), `이동평균`(파란 선, 굵게).
- **ReferenceLine**: `경고(35°C)` 주황 점선, `위험(45°C)` 빨강 점선. (값 = md)
- X축 시간(0~24시), Y축 범위 = md(예: 15~50).
- 상승 추세 감지 시: 해당 구간에 **ReferenceArea(붉은 음영)** + `상승 추세 감지` 배지.

### 패널 1-2: 가스 농도 이동평균 추세

- 시리즈: `가스 실측`(회색), `이동평균`(teal). ReferenceLine `경고(300ppm)`, `위험(500ppm)`.
- Y 0~500. 동반 상승 감지 구간에 붉은 음영 + `동반 상승 패턴` 배지.

### 카드 1(우): 설비 이상 조짐

- 상태 배지(예: `이상 조짐 감지`, 빨강) — 상태 판정 규칙은 md.
- `온도 변화율 +1.8°C/h`, `가스 변화율 +28ppm/h` (= 최근 구간 선형 기울기).
- `임계치 도달 예상 약 3.2시간 후` (= (위험임계−현재값)/변화율).

---

## 4. 행 2 — 필터 교체 예측

### 패널 2-1: ② 미세입자 일별 평균 추세

- **ComposedChart**: 일별 평균 **Bar**(보라) + `추세선`(보라 점선, 회귀) + 미래 **투영 구간**(옅은 배경).
- ReferenceLine `경고 임계치(75)`. X = `1일 ~ N일`(투영 포함), `30일(오늘)` 강조.
- 회귀 추세로 임계 도달 예상일을 투영해 표시.

### 패널 2-2: 주별 PM 베이스라인 상승

- **BarChart** 4주(`16.2 / 22.8 / 31.5 / 42.1` 등, 값 = md/계산). 막대 색은 **임계 대비 규칙**으로 조건부(임계 이하 green, 근접/초과 orange).
- ReferenceLine `경고 임계치`(점선). 각 막대 위 값 라벨.

### 카드 2(우): 필터 교체 예측

- 상태 배지(예: `교체 권장`, 주황) — 규칙 md.
- `필터 잔여 수명 38%` 진행 바.
- `현재 PM 평균 42.1 µg/m³`, `1주전 대비 +10.6 µg/m³ ↑`, `교체 권장: D+12일`.
- 잔여 수명·교체 예상일 산식은 md 규칙(누적 부하/임계 기반). ※ 추후 실제 모델로 교체할 placeholder로 함수 분리.

---

## 5. 행 3 — 수율 상관관계 (SECOM 기반)

### 패널 3-1: ③ 습도 vs 불량률 (SECOM)

- **ScatterChart**: X `습도(%)`, Y `불량률(%)`. 점 색: 정상 green / 경고(임계 초과) orange (임계 = md).
- **회귀선**(pink) + `상관계수 r=0.81` 라벨(= 피어슨 상관, 계산). `경고 임계치`(습도 80%) 수직 점선.

### 패널 3-2: 센서-불량률 상관계수 매트릭스

- **커스텀 히트맵 컴포넌트**(Recharts 미지원). 4×4(`온도/습도/가스/미세입자`) 피어슨 상관 값 표기.
- 색 스케일 `-1.00 ~ 1.00`(발산형, 시안은 초록 계열), 우측 컬러바. 값·색은 계산 또는 md 시드.

### 카드 3(우): 수율 상관관계

- `불량률 상관 Top 3`: 각 항목 색 막대 + r 값(예: 습도 0.81 / 온도 0.78 / 가스 0.44) — 상관 매트릭스에서 도출.
- 하단 강조 배너(green): `습도 80% 초과 시 불량률 평균 3.2배 증가` (문구·수치 = md).

---

## 6. 계산 로직 (파라미터는 md)

- **이동평균**: 윈도우 크기 = md.
- **변화율(기울기)**: 최근 구간 최소제곱 기울기 → °C/h, ppm/h 환산.
- **임계 도달 ETA**: `(위험임계 − 현재값) / 변화율`, 음수/발산 시 "해당 없음".
- **회귀선·상관계수 r**: 최소제곱 회귀 + 피어슨 상관.
- **상관 매트릭스**: 센서쌍 피어슨 r.
- **추세 상승 / 동반 상승 감지**: 최근 기울기가 md 임계를 넘으면 배지·음영 on.
- **필터 잔여 수명 / 교체 예상일**: md 규칙 기반. (placeholder — 추후 모델 교체 지점 함수 분리)

## 7. 색상·상태 규칙

- 정상/경고/위험 및 각 시리즈 색은 **md 팔레트** 사용. 시안 참고값: 온도 이동평균 파랑, 가스 teal, 미세입자 보라, 회귀선 pink, 위험 배지/라인 빨강, 경고 주황, 정상 green.
- 상태 배지·조건부 막대 색은 값과 md 임계 비교로 결정(하드코딩 금지).

## 8. 데이터 계약(예시)

`GET /api/analysis?device_id={id}&from={iso}&to={iso}` — 각 패널용 시리즈(온도/가스 이동평균, 미세입자 일별·주별, 습도-불량률 페어, 상관 매트릭스)와 파생 지표(변화율·ETA·잔여수명·상태)를 반환. 서버가 계산해 내려주거나, 원시 시계열만 받고 프론트에서 계산(임계·파라미터는 md). API 미연결 시 md 시드로 목업 렌더.

## 9. 수용 기준

- [ ] 시안과 동일한 3행 레이아웃(좌 차트 2 + 우 카드 1)이 재현된다.
- [ ] **화면의 모든 임계치·라벨·표시 수치가 md에서 로드**되며, 코드에 숫자 하드코딩이 없다.
- [ ] 각 차트에 임계 기준선/음영/배지가 규칙대로 표시된다.
- [ ] 상관 매트릭스가 값에 따라 색으로 렌더되고 컬러바가 있다.
- [ ] 회귀선/상관계수/변화율/ETA가 데이터로 계산되어 카드와 일치한다.
- [ ] 다크/라이트 모두 가독. API 없이도 md 시드로 렌더된다.
